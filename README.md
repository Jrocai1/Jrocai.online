# J-ROC AI Microsoft Agent Team

This package contains nine Microsoft Copilot Studio-ready agent definitions for Production Build 1.

Start with `deployment/COPILOT-STUDIO-SETUP.md`. Create the specialist agents first, then create the Production Build Coordinator and connect the specialists.

These files define the agents. Publishing them still requires a Microsoft Copilot Studio environment, configured knowledge sources, connections, tools, permissions, and testing.
